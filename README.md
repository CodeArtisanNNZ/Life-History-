# Life History

A black-and-white educational website combining scientific natural history with carefully sourced Islamic material.

## Run locally on Windows

1. Download or clone this repository.
2. Double-click `start-local.bat`.
3. Your browser will open:

**http://localhost:5500**

Keep the command window open while viewing the website. Close it to stop the local server.

### Manual alternative

From the project folder:

```powershell
py -m http.server 5500
```

Then open http://localhost:5500.

## Later deployment

After the local version is finalized, this project can be deployed to a subdomain such as:

`lifehistory.nusaibanusratzaman.me`

The current site is static, so it can be hosted easily on Vercel.
